A Python program (standard library only) that draws a newspaper front page summing up the world news of Saturday 21 November 2026: the UK and EU sign a post-Brexit reset deal covering food trade, linked emissions trading and a Youth Experience Scheme, Russian missiles and a drone come down inside Poland during a huge overnight barrage on Ukraine, a magnitude 6.9 earthquake shakes Peru's Andes with no damage reported, and hackers breach the FBI and the US Agriculture Department amid spreading computer outages. It writes a 1024x1024 PNG to /output/entry.png, deterministically and with no network.

## Run it

```sh
python3 main.py
```
